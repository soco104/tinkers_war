# Tinker's War

A small top-down steampunk stealth game made with Phaser 3.

## Run it

The game loads its art from the `art/` folder, which browsers only allow over http, so it
needs a tiny local server (included, no install beyond [Node.js](https://nodejs.org)):

- **Windows:** double-click `start.bat`, or
- **any system:** run `node serve.js` and open http://localhost:8000

## Controls

- **Space**: advance dialogue / swing the wrench
- **Esc**: skip a cutscene
- **WASD / arrow keys**: move
- **E**: sabotage a furnace
- **R**: play again after winning
